# Fonts

## NotoNaskhArabic-Regular.ttf

- **Keluarga:** Noto Naskh Arabic
- **Sumber:** Google Fonts (varian variabel, instance default = Regular)
  <https://github.com/google/fonts/tree/main/ofl/notonaskharabic>
- **Lisensi:** SIL Open Font License 1.1 (OFL-1.1)
- **Kegunaan:** menampilkan Bahasa Indonesia **dan** teks Arab (termasuk
  harakat) pada PDF. Font ini mencakup glyph Latin dan Arab.

Portofolio font ini disertakan sesuai PRD §14 (font Arab disertakan dalam
project). Jika mengganti font, pastikan mendukung Latin + Arab + harakat,
lalu ubah `FONT_PATH` di `src/pdf/generator.js`.
